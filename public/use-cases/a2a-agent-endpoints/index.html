Agent-to-Agent (A2A) Protocol Endpoints with AgentDomains

Publish /.well-known/agent.json Agent Cards and A2A task endpoints over HTTPS on *.agentdomains.co.

Example Host a2a-research.agentdomains.co
MCP Flow 4 Tool Steps
HTTPS Mode Edge Proxy
Teardown GitHub Action

Inter-agent discovery protocols like A2A require public HTTPS endpoints serving a verifiable Agent Card at /.well-known/agent.json. AgentDomains gives each specialized agent its own identity in seconds.

1. 3-Stage Sequence Diagram

3-stage sequence: AI agent claims a2a-research.agentdomains.co, maps it to a2a-research.fly.dev, and verifies HTTPS 200 OK.

2. 4-Step MCP Tool-Call Transcript

Your agent sends these exact calls to https://mcp.agentdomains.co or local stdio.

STEP 1check_availability
REQ → check_availability("a2a-research") RES ← available: true
MCP Call → check_availability 
{
  "tool": "check_availability",
  "arguments": {
    "label": "a2a-research",
    "domain": "agentdomains.co"
  }
}
// Response:
{
  "fqdn": "a2a-research.agentdomains.co",
  "available": true,
  "reason": "available"
}
STEP 2claim_domain
REQ → claim_domain("a2a-research") RES ← status: "claimed"
MCP Call → claim_domain 
{
  "tool": "claim_domain",
  "arguments": {
    "label": "a2a-research",
    "domain": "agentdomains.co",
    "email": "ops@example.com"
  }
}
// Response:
{
  "fqdn": "a2a-research.agentdomains.co",
  "status": "claimed",
  "confirm_within_days": 30
}
STEP 3set_proxy
REQ → set_proxy("a2a-research.fly.dev") RES ← ok: true
MCP Call → set_proxy 
{
  "tool": "set_proxy",
  "arguments": {
    "label": "a2a-research",
    "domain": "agentdomains.co",
    "origin": "a2a-research.fly.dev"
  }
}
// Response:
{
  "ok": true,
  "fqdn": "a2a-research.agentdomains.co",
  "origin": "a2a-research.fly.dev",
  "https": "https://a2a-research.agentdomains.co"
}
STEP 4Verify Live HTTPS (200 OK)
REQ → HEAD https://a2a-research.agentdomains.co RES ← HTTP/2 200 OK
Verify live HTTPS response 
curl -fsSI https://a2a-research.agentdomains.co
# HTTP/2 200
# content-type: application/json
# strict-transport-security: max-age=31536000

3. Clean Teardown (GitHub Action & CLI)

Deregister the Agent Card from your orchestrator before calling delete_domain. Delete the DNS mapping before you destroy your cloud server to block dangling takeovers.

.github/workflows/teardown-domain.yml 
name: Teardown a2a-research
on:
  workflow_dispatch:
  pull_request:
    types: [closed]
jobs:
  cleanup:
    runs-on: ubuntu-latest
    steps:
      - name: Delete AgentDomains hostname before destroying compute
        env:
          AGENTDOMAINS_API_KEY: ${{ secrets.AGENTDOMAINS_API_KEY }}
        run: |
          curl -fsSL -X DELETE \
            -H "Authorization: Bearer $AGENTDOMAINS_API_KEY" \
            "https://api.agentdomains.co/v1/subdomains/a2a-research?domain=agentdomains.co"
      # Or with the Go CLI:
      # agentdomains delete a2a-research --domain agentdomains.co
