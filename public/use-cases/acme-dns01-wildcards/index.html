ACME DNS-01 & Private TLS Certs with AgentDomains

Automate Let’s Encrypt `_acme-challenge` TXT records via MCP (`add_acme_challenge`) or CLI (`agentdomains txt`) for boxes behind NAT or firewalled port 80.

Example Host: internal-ca.makes.fyi 4-Step MCP Transcript CI Teardown Included

HTTP-01 fails whenever port 80 is blocked or a service is internal-only. `add_acme_challenge` publishes the exact `_acme-challenge` TXT token in seconds so Certbot, Caddy, or acme.sh issues trusted certs.

2. 4-Step MCP Tool-Call Transcript

Here is the exact sequence an agent executes against https://mcp.agentdomains.co (or local stdio npx -y agentdomains-mcp):

STEP 1check_availability
MCP Call → check_availability 
{
  "tool": "check_availability",
  "arguments": {
    "label": "internal-ca",
    "domain": "makes.fyi"
  }
}
// Response:
{
  "fqdn": "internal-ca.makes.fyi",
  "available": true,
  "reason": "available"
}
STEP 2claim_domain
MCP Call → claim_domain 
{
  "tool": "claim_domain",
  "arguments": {
    "label": "internal-ca",
    "domain": "makes.fyi",
    "email": "ops@example.com"
  }
}
// Response:
{
  "fqdn": "internal-ca.makes.fyi",
  "status": "claimed",
  "confirm_within_days": 30
}
STEP 3add_acme_challenge
MCP Call → add_acme_challenge 
{
  "tool": "add_acme_challenge",
  "arguments": {
    "label": "internal-ca",
    "domain": "makes.fyi",
    "value": "k9Lm2_acme_challenge_token"
  }
}
// Response:
{
  "ok": true,
  "id": "rec_acme1",
  "host": "_acme-challenge.internal-ca.makes.fyi",
  "type": "TXT"
}
STEP 4Live Verification (200 OK)
Verify live HTTPS response 
curl -fsSI https://internal-ca.makes.fyi
# HTTP/2 200
# content-type: application/json
# strict-transport-security: max-age=31536000

3. Clean Teardown (GitHub Action & CLI)

Clean up spent `_acme-challenge` TXT records with `delete_record` after issuance. Always delete the DNS/proxy mapping before deleting your upstream cloud resource to prevent dangling subdomain takeovers.

.github/workflows/teardown-domain.yml 
name: Teardown internal-ca
on:
  workflow_dispatch:
  pull_request:
    types: [closed]
jobs:
  cleanup:
    runs-on: ubuntu-latest
    steps:
      - name: Delete AgentDomains hostname before destroying compute
        env:
          AGENTDOMAINS_API_KEY: ${{ secrets.AGENTDOMAINS_API_KEY }}
        run: |
          curl -fsSL -X DELETE \
            -H "Authorization: Bearer $AGENTDOMAINS_API_KEY" \
            "https://api.agentdomains.co/v1/subdomains/internal-ca"
      # Or with the Go CLI:
      # agentdomains delete internal-ca
