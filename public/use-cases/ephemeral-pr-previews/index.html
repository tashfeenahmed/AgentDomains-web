2. 4-Step MCP Tool-Call Transcript

Your agent sends these exact calls to https://mcp.agentdomains.co or local stdio.

MCP Call → check_availability

3. Clean Teardown (GitHub Action & CLI)

Trigger agentdomains delete pr-$PR_NUMBER-web automatically on pull_request: [closed]. Delete the DNS mapping before you destroy your cloud server to block dangling takeovers.

.github/workflows/teardown-domain.yml 
name: Teardown pr-142-web
on:
  workflow_dispatch:
  pull_request:
    types: [closed]
jobs:
  cleanup:
    runs-on: ubuntu-latest
    steps:
      - name: Delete AgentDomains hostname before destroying compute
        env:
          AGENTDOMAINS_API_KEY: ${{ secrets.AGENTDOMAINS_API_KEY }}
        run: |
          curl -fsSL -X DELETE \
            -H "Authorization: Bearer $AGENTDOMAINS_API_KEY" \
            "https://api.agentdomains.co/v1/subdomains/pr-142-web"
      # Or with the Go CLI:
      # agentdomains delete pr-142-web
