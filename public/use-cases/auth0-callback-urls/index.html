Auth0 Allowed Callback & Logout URLs with AgentDomains

Configure Auth0 Allowed Callback URLs, Logout URLs, and Web Origins on a predictable HTTPS staging hostname.

Example Host: auth0-demo.makes.fyi 4-Step MCP Transcript CI Teardown Included

Auth0 throws `Callback URL mismatch` on any ephemeral hostname change. Proxying through a fixed `makes.fyi` name keeps Auth0 tenants stable across deployments.

2. 4-Step MCP Tool-Call Transcript

Here is the exact sequence an agent executes against https://mcp.agentdomains.co (or local stdio npx -y agentdomains-mcp):

STEP 1check_availability
MCP Call → check_availability 
{
  "tool": "check_availability",
  "arguments": {
    "label": "auth0-demo",
    "domain": "makes.fyi"
  }
}
// Response:
{
  "fqdn": "auth0-demo.makes.fyi",
  "available": true,
  "reason": "available"
}
STEP 2claim_domain
MCP Call → claim_domain 
{
  "tool": "claim_domain",
  "arguments": {
    "label": "auth0-demo",
    "domain": "makes.fyi",
    "email": "ops@example.com"
  }
}
// Response:
{
  "fqdn": "auth0-demo.makes.fyi",
  "status": "claimed",
  "confirm_within_days": 30
}
STEP 3set_proxy
MCP Call → set_proxy 
{
  "tool": "set_proxy",
  "arguments": {
    "label": "auth0-demo",
    "domain": "makes.fyi",
    "origin": "auth0-demo.up.railway.app"
  }
}
// Response:
{
  "ok": true,
  "fqdn": "auth0-demo.makes.fyi",
  "origin": "auth0-demo.up.railway.app",
  "https": "https://auth0-demo.makes.fyi"
}
STEP 4Live Verification (200 OK)
Verify live HTTPS response 
curl -fsSI https://auth0-demo.makes.fyi
# HTTP/2 200
# content-type: application/json
# strict-transport-security: max-age=31536000

3. Clean Teardown (GitHub Action & CLI)

Remove staging URLs from your Auth0 Application settings when deleting the preview. Always delete the DNS/proxy mapping before deleting your upstream cloud resource to prevent dangling subdomain takeovers.

.github/workflows/teardown-domain.yml 
name: Teardown auth0-demo
on:
  workflow_dispatch:
  pull_request:
    types: [closed]
jobs:
  cleanup:
    runs-on: ubuntu-latest
    steps:
      - name: Delete AgentDomains hostname before destroying compute
        env:
          AGENTDOMAINS_API_KEY: ${{ secrets.AGENTDOMAINS_API_KEY }}
        run: |
          curl -fsSL -X DELETE \
            -H "Authorization: Bearer $AGENTDOMAINS_API_KEY" \
            "https://api.agentdomains.co/v1/subdomains/auth0-demo"
      # Or with the Go CLI:
      # agentdomains delete auth0-demo
