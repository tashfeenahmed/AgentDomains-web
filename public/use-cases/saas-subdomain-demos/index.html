Multi-Tenant SaaS Subdomain Demos with AgentDomains

Test tenant-per-subdomain routing (`acme.tenant-demo.makes.fyi`, `beta.tenant-demo.makes.fyi`) using AgentDomains sub-label DNS records (`--host`).

Example Host: tenant-demo.makes.fyi 4-Step MCP Transcript CI Teardown Included

One claimed subdomain lets you create arbitrary deeper sub-labels (`--host acme`, `--host beta`) so you can validate multi-tenant cookie scoping and Host-header routing realistically.

2. 4-Step MCP Tool-Call Transcript

Here is the exact sequence an agent executes against https://mcp.agentdomains.co (or local stdio npx -y agentdomains-mcp):

STEP 1check_availability
MCP Call → check_availability 
{
  "tool": "check_availability",
  "arguments": {
    "label": "tenant-demo",
    "domain": "makes.fyi"
  }
}
// Response:
{
  "fqdn": "tenant-demo.makes.fyi",
  "available": true,
  "reason": "available"
}
STEP 2claim_domain
MCP Call → claim_domain 
{
  "tool": "claim_domain",
  "arguments": {
    "label": "tenant-demo",
    "domain": "makes.fyi",
    "email": "ops@example.com"
  }
}
// Response:
{
  "fqdn": "tenant-demo.makes.fyi",
  "status": "claimed",
  "confirm_within_days": 30
}
STEP 3add_dns_record
MCP Call → add_dns_record 
{
  "tool": "add_dns_record",
  "arguments": {
    "label": "tenant-demo",
    "domain": "makes.fyi",
    "type": "A",
    "content": "203.0.113.48"
  }
}
// Response:
{
  "ok": true,
  "id": "rec_01j8x",
  "fqdn": "tenant-demo.makes.fyi",
  "type": "A",
  "content": "203.0.113.48"
}
STEP 4Live Verification (200 OK)
Verify live HTTPS response 
curl -fsSI https://tenant-demo.makes.fyi
# HTTP/2 200
# content-type: application/json
# strict-transport-security: max-age=31536000

3. Clean Teardown (GitHub Action & CLI)

Deleting the parent label cleans up every tenant sub-label atomically. Always delete the DNS/proxy mapping before deleting your upstream cloud resource to prevent dangling subdomain takeovers.

.github/workflows/teardown-domain.yml 
name: Teardown tenant-demo
on:
  workflow_dispatch:
  pull_request:
    types: [closed]
jobs:
  cleanup:
    runs-on: ubuntu-latest
    steps:
      - name: Delete AgentDomains hostname before destroying compute
        env:
          AGENTDOMAINS_API_KEY: ${{ secrets.AGENTDOMAINS_API_KEY }}
        run: |
          curl -fsSL -X DELETE \
            -H "Authorization: Bearer $AGENTDOMAINS_API_KEY" \
            "https://api.agentdomains.co/v1/subdomains/tenant-demo"
      # Or with the Go CLI:
      # agentdomains delete tenant-demo
