2. 4-Step MCP Tool-Call Transcript

Here is the exact sequence an agent executes against https://mcp.agentdomains.co (or local stdio npx -y agentdomains-mcp):

STEP 1check_availability
MCP Call → check_availability 
{
  "tool": "check_availability",
  "arguments": {
    "label": "my-mcp-srv",
    "domain": "agentdomains.co"
  }
}
// Response:
{
  "fqdn": "my-mcp-srv.agentdomains.co",
  "available": true,
  "reason": "available"
}
STEP 2claim_domain
MCP Call → claim_domain 
{
  "tool": "claim_domain",
  "arguments": {
    "label": "my-mcp-srv",
    "domain": "agentdomains.co",
    "email": "ops@example.com"
  }
}
// Response:
{
  "fqdn": "my-mcp-srv.agentdomains.co",
  "status": "claimed",
  "confirm_within_days": 30
}
STEP 3set_proxy
MCP Call → set_proxy 
{
  "tool": "set_proxy",
  "arguments": {
    "label": "my-mcp-srv",
    "domain": "agentdomains.co",
    "origin": "my-mcp-srv.fly.dev"
  }
}
// Response:
{
  "ok": true,
  "fqdn": "my-mcp-srv.agentdomains.co",
  "origin": "my-mcp-srv.fly.dev",
  "https": "https://my-mcp-srv.agentdomains.co"
}
STEP 4Live Verification (200 OK)
Verify live HTTPS response 
curl -fsSI https://my-mcp-srv.agentdomains.co
# HTTP/2 200
# content-type: application/json
# strict-transport-security: max-age=31536000

3. Clean Teardown (GitHub Action & CLI)

Use `agentdomains remove-proxy` or `delete` when retiring old MCP prototypes. Always delete the DNS/proxy mapping before deleting your upstream cloud resource to prevent dangling subdomain takeovers.

.github/workflows/teardown-domain.yml 
name: Teardown my-mcp-srv
on:
  workflow_dispatch:
  pull_request:
    types: [closed]
jobs:
  cleanup:
    runs-on: ubuntu-latest
    steps:
      - name: Delete AgentDomains hostname before destroying compute
        env:
          AGENTDOMAINS_API_KEY: ${{ secrets.AGENTDOMAINS_API_KEY }}
        run: |
          curl -fsSL -X DELETE \
            -H "Authorization: Bearer $AGENTDOMAINS_API_KEY" \
            "https://api.agentdomains.co/v1/subdomains/my-mcp-srv?domain=agentdomains.co"
      # Or with the Go CLI:
      # agentdomains delete my-mcp-srv --domain agentdomains.co
