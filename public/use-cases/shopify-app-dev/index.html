Shopify Custom App Development with AgentDomains

Keep one fixed HTTPS App URL and OAuth callback for Shopify dev stores across restarts.

Example Host shopify-dev.makes.fyi
MCP Flow 4 Tool Steps
HTTPS Mode Edge Proxy
Teardown GitHub Action

Shopify enforces strict HTTPS redirect lists. A fixed shopify-dev.makes.fyi URL saves hours during testing.

1. 3-Stage Sequence Diagram

3-stage sequence: AI agent claims shopify-dev.makes.fyi, maps it to shopify-dev.fly.dev, and verifies HTTPS 200 OK.

2. 4-Step MCP Tool-Call Transcript

Your agent sends these exact calls to https://mcp.agentdomains.co or local stdio.

STEP 1check_availability
REQ → check_availability("shopify-dev") RES ← available: true
MCP Call → check_availability 
{
  "tool": "check_availability",
  "arguments": {
    "label": "shopify-dev",
    "domain": "makes.fyi"
  }
}
// Response:
{
  "fqdn": "shopify-dev.makes.fyi",
  "available": true,
  "reason": "available"
}
STEP 2claim_domain
REQ → claim_domain("shopify-dev") RES ← status: "claimed"
MCP Call → claim_domain 
{
  "tool": "claim_domain",
  "arguments": {
    "label": "shopify-dev",
    "domain": "makes.fyi",
    "email": "ops@example.com"
  }
}
// Response:
{
  "fqdn": "shopify-dev.makes.fyi",
  "status": "claimed",
  "confirm_within_days": 30
}
STEP 3set_proxy
REQ → set_proxy("shopify-dev.fly.dev") RES ← ok: true
MCP Call → set_proxy 
{
  "tool": "set_proxy",
  "arguments": {
    "label": "shopify-dev",
    "domain": "makes.fyi",
    "origin": "shopify-dev.fly.dev"
  }
}
// Response:
{
  "ok": true,
  "fqdn": "shopify-dev.makes.fyi",
  "origin": "shopify-dev.fly.dev",
  "https": "https://shopify-dev.makes.fyi"
}
STEP 4Verify Live HTTPS (200 OK)
REQ → HEAD https://shopify-dev.makes.fyi RES ← HTTP/2 200 OK
Verify live HTTPS response 
curl -fsSI https://shopify-dev.makes.fyi
# HTTP/2 200
# content-type: application/json
# strict-transport-security: max-age=31536000

3. Clean Teardown (GitHub Action & CLI)

Keep the name on Pro if merchant dev stores remain installed. Delete the DNS mapping before you destroy your cloud server to block dangling takeovers.

.github/workflows/teardown-domain.yml 
name: Teardown shopify-dev
on:
  workflow_dispatch:
  pull_request:
    types: [closed]
jobs:
  cleanup:
    runs-on: ubuntu-latest
    steps:
      - name: Delete AgentDomains hostname before destroying compute
        env:
          AGENTDOMAINS_API_KEY: ${{ secrets.AGENTDOMAINS_API_KEY }}
        run: |
          curl -fsSL -X DELETE \
            -H "Authorization: Bearer $AGENTDOMAINS_API_KEY" \
            "https://api.agentdomains.co/v1/subdomains/shopify-dev"
      # Or with the Go CLI:
      # agentdomains delete shopify-dev
