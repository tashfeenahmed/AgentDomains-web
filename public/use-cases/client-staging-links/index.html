2. 4-Step MCP Tool-Call Transcript

Here is the exact sequence an agent executes against https://mcp.agentdomains.co (or local stdio npx -y agentdomains-mcp):

STEP 1check_availability
MCP Call → check_availability 
{
  "tool": "check_availability",
  "arguments": {
    "label": "acme-stage",
    "domain": "makes.fyi"
  }
}
// Response:
{
  "fqdn": "acme-stage.makes.fyi",
  "available": true,
  "reason": "available"
}
STEP 2claim_domain
MCP Call → claim_domain 
{
  "tool": "claim_domain",
  "arguments": {
    "label": "acme-stage",
    "domain": "makes.fyi",
    "email": "ops@example.com"
  }
}
// Response:
{
  "fqdn": "acme-stage.makes.fyi",
  "status": "claimed",
  "confirm_within_days": 30
}
STEP 3set_proxy
MCP Call → set_proxy 
{
  "tool": "set_proxy",
  "arguments": {
    "label": "acme-stage",
    "domain": "makes.fyi",
    "origin": "acme-stage.up.railway.app"
  }
}
// Response:
{
  "ok": true,
  "fqdn": "acme-stage.makes.fyi",
  "origin": "acme-stage.up.railway.app",
  "https": "https://acme-stage.makes.fyi"
}
STEP 4Live Verification (200 OK)
Verify live HTTPS response 
curl -fsSI https://acme-stage.makes.fyi
# HTTP/2 200
# content-type: application/json
# strict-transport-security: max-age=31536000

3. Clean Teardown (GitHub Action & CLI)

Archive finished client staging URLs with `agentdomains delete` or switch them to a 301 forward to production. Always delete the DNS/proxy mapping before deleting your upstream cloud resource to prevent dangling subdomain takeovers.

.github/workflows/teardown-domain.yml 
name: Teardown acme-stage
on:
  workflow_dispatch:
  pull_request:
    types: [closed]
jobs:
  cleanup:
    runs-on: ubuntu-latest
    steps:
      - name: Delete AgentDomains hostname before destroying compute
        env:
          AGENTDOMAINS_API_KEY: ${{ secrets.AGENTDOMAINS_API_KEY }}
        run: |
          curl -fsSL -X DELETE \
            -H "Authorization: Bearer $AGENTDOMAINS_API_KEY" \
            "https://api.agentdomains.co/v1/subdomains/acme-stage"
      # Or with the Go CLI:
      # agentdomains delete acme-stage
