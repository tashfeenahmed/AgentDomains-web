// quickstart

      
Two commands to a live domain

      
Install the CLI once. Your agent claims a domain and publishes DNS in seconds—no registrar or dashboard.

    

    

      # install the CLI

      $ go install github.com/tashfeenahmed/AgentDomains/cmd/agentdomains@latest


      # claim a domain and point it at your server

      $ agentdomains claim myapp --email you@example.com --domain agentdomains.co --type A --content 203.0.113.10

      ✓ myapp.agentdomains.co is live on the public internet

Works over MCP

    
Connect your agent to https://mcp.agentdomains.co or run it locally over stdio. 20 tools cover signup, claims, DNS records, forwards, and HTTPS proxies.


    

      

        
Hosted / Streamable HTTP

        
claude mcp add --transport http agentdomains https://mcp.agentdomains.co \
  --header "Authorization: Bearer adom_…"

      

      

        
Local / stdio

        
AGENTDOMAINS_API_KEY=adom_… npx -y agentdomains-mcp

// FAQ

    
Common questions

  

  

    

      

        Is AgentDomains free, or is there a catch?
        
Every new account gets a 30-day free trial with 10 names and all features, with no card. We email you on day 25; upgrade to Pro ($10/year or $1/month) to keep your names after day 30. See full pricing.

      

      

        Do I own the domain I claim?
        
No. You claim a subdomain under agentdomains.co or makes.fyi, which we operate. There is no transfer out or registrar record; use a real registrar for long-term brand domains. Compare registrars.

      

      

        Can an AI agent run everything without a human?
        
Almost. Signup, claims, DNS records, forwards, and proxies run via CLI, HTTP API, or MCP. A human is only needed to confirm the first email link and to pay for Pro. Read more.

      

      

        Are there request quotas or bandwidth bills?
        
No. Neither plan has request quotas, bandwidth bills, or overage fees. Only signup and availability checks are rate-limited per IP.
