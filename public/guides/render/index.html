Frequently asked questions

  

    
Should I use edge proxy or an A record for Render?
Use `agentdomains proxy` targeting `<service>.onrender.com` for immediate HTTPS on your custom makes.fyi or agentdomains.co hostname.

    
How do I verify DNS propagation for Render?
After running the CLI commands above, open our free /tools/dns-ssl-checker or run dig @1.1.1.1 render-bot.makes.fyi to confirm Cloudflare and Google resolvers return your new record.

    
Can an AI agent set up Render routing automatically via MCP?
Yes. Connect Claude Code, Cursor, or any MCP client to https://mcp.agentdomains.co and ask it to run claim_domain followed by set_proxy.

  




      
Related Host Playbooks

      

        
          PaaS & Containers
          
Fly.io

          
Use `agentdomains proxy` directly against `<app>.fly.dev`. You get instant edge HTTPS without running `fly certs add` or paying for a dedicated IPv4.

        
        
          PaaS & Containers
          
Railway

          
Use `agentdomains proxy` pointing at your `*.up.railway.app` hostname. Zero custom-domain verification wait and instant HTTPS at our edge.

        
        
          Homelab & Self-Hosted
          
Raspberry Pi

          
If you have a public IP + port forwarding, set an A record and run Caddy with ACME DNS-01. If you are behind CGNAT, expose via Tailscale Funnel/Cloudflare Tunnel and point `agentdomains proxy` at that hostname.

        
        
          Containers & Orchestration
          
Docker Compose

          
Point an A record to your Docker host IP and run a lightweight Caddy or Traefik container alongside your app services to handle HTTPS and container routing.
