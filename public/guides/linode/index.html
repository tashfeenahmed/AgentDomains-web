Frequently asked questions

  

    
Should I use edge proxy or an A record for Linode (Akamai Cloud)?
Set an A record (and optional AAAA) to your Linode IP and let Caddy or Certbot handle TLS.

    
How do I verify DNS propagation for Linode (Akamai Cloud)?
After running the CLI commands above, open our free /tools/dns-ssl-checker or run dig @1.1.1.1 linode-api.makes.fyi to confirm Cloudflare and Google resolvers return your new record.

    
Can an AI agent set up Linode (Akamai Cloud) routing automatically via MCP?
Yes. Connect Claude Code, Cursor, or any MCP client to https://mcp.agentdomains.co and ask it to run claim_domain followed by add_dns_record.
