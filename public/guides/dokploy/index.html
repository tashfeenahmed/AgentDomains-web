Frequently asked questions

  

    
Should I use edge proxy or an A record for Dokploy?
Create an A record pointing to your Dokploy server IP, add `dokploy-srv.makes.fyi` in Dokploy’s Domains tab, and toggle HTTPS (Let’s Encrypt) on.

    
How do I verify DNS propagation for Dokploy?
After running the CLI commands above, open our free /tools/dns-ssl-checker or run dig @1.1.1.1 dokploy-srv.makes.fyi to confirm Cloudflare and Google resolvers return your new record.

    
Can an AI agent set up Dokploy routing automatically via MCP?
Yes. Connect Claude Code, Cursor, or any MCP client to https://mcp.agentdomains.co and ask it to run claim_domain followed by add_dns_record.

  




      
Related Host Playbooks

      

        
          Self-Hosted PaaS
          
Coolify

          
Point an A record (plus an optional wildcard `*.coolify-box.makes.fyi` or individual sub-labels) to your Coolify VPS IP, then enter `https://coolify-box.makes.fyi` in Coolify’s Domains field.

        
        
          Self-Hosted PaaS
          
Kamal (kamal-proxy)

          
Point an A record at your Kamal host IP and set `proxy: ssl: true` with `host: kamal-app.makes.fyi` in `config/deploy.yml`. Kamal-proxy handles Let’s Encrypt automatically.

        
        
          Major Clouds
          
AWS EC2

          
Attach an Elastic IP to your EC2 instance and point an A record at it (with Caddy/Nginx TLS), OR if you sit behind an AWS Application Load Balancer (`*.elb.amazonaws.com`), use `agentdomains proxy` for zero ACM cert paperwork.

        
        
          Major Clouds
          
AWS Lightsail

          
Attach a free Lightsail Static IP, create an A record with `agentdomains record`, and terminate HTTPS via Caddy or Bitnami’s `bncert-tool`.
