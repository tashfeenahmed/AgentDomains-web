1. Choose Mode: Edge Proxy vs DNS-01

Edge HTTPS Reverse Proxy

FOR PAAS HOSTS
  • Point at any public hostname without https://.
  • Cloudflare edge handles TLS 1.3 automatically.
  • Zero Certbot config and zero IP exposure.

A Record + ACME DNS-01

PICK FOR RASPBERRY PI
  • Point directly at your server IPv4 or IPv6 address.
  • Issue certs via Caddy or agentdomains txt DNS-01.
  • Works even when your firewall blocks port 80.
Raspberry Pi — 3-command AgentDomains setup 
agentdomains signup
agentdomains claim pi-lab --email you@example.com
agentdomains record pi-lab --type A --content 203.0.113.42

Frequently asked questions

  

    
Should I use edge proxy or an A record for Raspberry Pi?
With a public IP, set an A record and run Caddy. Behind CGNAT, run Tailscale Funnel or Cloudflare Tunnel behind `agentdomains proxy`.

    
How do I check DNS propagation for Raspberry Pi?
Open /tools/dns-ssl-checker or run dig @1.1.1.1 pi-lab.makes.fyi. Confirm both Cloudflare and Google return your record.

    
Can an AI agent configure Raspberry Pi routing via MCP?
Yes. Connect your client to https://mcp.agentdomains.co. Ask it to call claim_domain and add_dns_record.
