Frequently asked questions

  

    
Should I use edge proxy or an A record for Localhost Staging & Tunnel Fronting?
AgentDomains does not terminate NAT tunnels itself — pair a free `cloudflared tunnel --url http://localhost:3000` (or Tailscale Funnel) with `agentdomains proxy` so your localhost staging URL NEVER changes!

    
How do I verify DNS propagation for Localhost Staging & Tunnel Fronting?
After running the CLI commands above, open our free /tools/dns-ssl-checker or run dig @1.1.1.1 local-dev.makes.fyi to confirm Cloudflare and Google resolvers return your new record.

    
Can an AI agent set up Localhost Staging & Tunnel Fronting routing automatically via MCP?
Yes. Connect Claude Code, Cursor, or any MCP client to https://mcp.agentdomains.co and ask it to run claim_domain followed by set_proxy.

  




      
Related Host Playbooks

      

        
          Cloud VPS
          
Hetzner Cloud VPS

          
Use an A record (plus optional AAAA for Hetzner’s free /64 IPv6) and terminate TLS on your VPS with Caddy or Certbot DNS-01. Remember: AgentDomains edge proxy requires an upstream hostname, not a bare IP.

        
        
          Cloud VPS
          
DigitalOcean Droplet

          
Point an A record straight at your Droplet’s public IPv4 and let Caddy or Nginx + Certbot issue a Let’s Encrypt cert via HTTP-01 or AgentDomains DNS-01.

        
        
          PaaS & Containers
          
Fly.io

          
Use `agentdomains proxy` directly against `<app>.fly.dev`. You get instant edge HTTPS without running `fly certs add` or paying for a dedicated IPv4.

        
        
          PaaS & Containers
          
Railway

          
Use `agentdomains proxy` pointing at your `*.up.railway.app` hostname. Zero custom-domain verification wait and instant HTTPS at our edge.
