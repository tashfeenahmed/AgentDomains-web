Frequently asked questions

  

    
Should I use edge proxy or an A record for Lovable?
Use `agentdomains forward` for instant memorable links to `*.lovable.app`, or export your Lovable GitHub repo to Railway/Render/Fly and front it with `agentdomains proxy`.

    
How do I verify DNS propagation for Lovable?
After running the CLI commands above, open our free /tools/dns-ssl-checker or run dig @1.1.1.1 lovable-mvp.makes.fyi to confirm Cloudflare and Google resolvers return your new record.

    
Can an AI agent set up Lovable routing automatically via MCP?
Yes. Connect Claude Code, Cursor, or any MCP client to https://mcp.agentdomains.co and ask it to run claim_domain followed by set_forward.
