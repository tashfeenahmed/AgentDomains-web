Should I use edge proxy or an A record for FastAPI (Python)?

How do I verify DNS propagation for FastAPI (Python)?
After running the CLI commands above, open our free /tools/dns-ssl-checker or run dig @1.1.1.1 fastapi-demo.makes.fyi to confirm Cloudflare and Google resolvers return your new record.

Related Host Playbooks

      

        
          Web Frameworks
          
Next.js

          
Use `agentdomains proxy` when hosting Next.js on Railway, Fly.io, or Render. For Vercel deployments, note that Vercel checks the Host header — either configure custom domain CNAME or proxy a self-hosted `next start` origin.

        
        
          Web Frameworks
          
Express.js (Node)

          
Put `agentdomains proxy` in front of your PaaS-hosted Express app, or point an A record at your VPS + Caddy. Enable `trust proxy` in Express so `req.ip` and `req.protocol` work accurately.

        
        
          Web Frameworks
          
Go net/http

          
Point an A record directly at your Linux box and serve native HTTPS right from Go’s `golang.org/x/crypto/acme/autocert` — zero external reverse proxy needed!

        
        
          Web Frameworks
          
Flask (Python)

          
Use `agentdomains proxy` in front of Render/Railway/Fly Gunicorn deployments and wrap Flask with Werkzeug’s `ProxyFix` middleware.
