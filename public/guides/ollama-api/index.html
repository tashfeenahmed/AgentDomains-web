3. Ollama Local LLM API Origin Configuration

      

  

    Ollama Local LLM API server / platform config
    
  

  
# /etc/caddy/Caddyfile — protect Ollama with a Bearer token!
ollama-node.makes.fyi {
    @unauth not header Authorization "Bearer YOUR_SECRET_TOKEN"
    respond @unauth 401
    reverse_proxy 127.0.0.1:11434
}



      

        
Operational Checklist

        
    
          
  • Ollama ships with zero built-in authentication — always enforce an Authorization header in Caddy/Nginx before exposing an HTTPS domain.
    • 
          
  • Set `OLLAMA_ORIGINS="https://*"` only if browser apps call your endpoint directly.

Frequently asked questions

  

    
Should I use edge proxy or an A record for Ollama Local LLM API?
Point an A record at your GPU box and terminate TLS + Bearer token auth in Caddy before forwarding to `127.0.0.1:11434`. Never expose raw unauthenticated Ollama on port 11434!

    
How do I verify DNS propagation for Ollama Local LLM API?
After running the CLI commands above, open our free /tools/dns-ssl-checker or run dig @1.1.1.1 ollama-node.makes.fyi to confirm Cloudflare and Google resolvers return your new record.

    
Can an AI agent set up Ollama Local LLM API routing automatically via MCP?
Yes. Connect Claude Code, Cursor, or any MCP client to https://mcp.agentdomains.co and ask it to run claim_domain followed by add_dns_record.
