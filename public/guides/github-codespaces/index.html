Origin-to-edge flow for GitHub Codespaces: connect studious-space-xxxx-3000.app.github.dev to cs-preview.agentdomains.co with automatic HTTPS.

1. Choose Mode: Edge Proxy vs DNS-01

Edge HTTPS Reverse Proxy

RECOMMENDED
  • Point at any public hostname without https://.
  • Cloudflare edge handles TLS 1.3 automatically.
  • Zero Certbot config and zero IP exposure.

A Record + ACME DNS-01

FOR BARE VPS
  • Point directly at your server IPv4 or IPv6 address.
  • Issue certs via Caddy or agentdomains txt DNS-01.
  • Works even when your firewall blocks port 80.
GitHub Codespaces — 3-command AgentDomains setup 
agentdomains signup
agentdomains claim cs-preview --email you@example.com --domain agentdomains.co
agentdomains proxy cs-preview studious-space-xxxx-3000.app.github.dev --domain agentdomains.co

Frequently asked questions

  

    
Should I use edge proxy or an A record for GitHub Codespaces?
Set your Codespaces port to Public, then run agentdomains proxy. Share cs-preview.makes.fyi instead of a long .github.dev URL.

    
How do I check DNS propagation for GitHub Codespaces?
Open /tools/dns-ssl-checker or run dig @1.1.1.1 cs-preview.agentdomains.co. Confirm both Cloudflare and Google return your record.

    
Can an AI agent configure GitHub Codespaces routing via MCP?
Yes. Connect your client to https://mcp.agentdomains.co. Ask it to call claim_domain and set_proxy.
