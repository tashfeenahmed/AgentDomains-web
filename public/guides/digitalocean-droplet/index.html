Frequently asked questions

  

    
Should I use edge proxy or an A record for DigitalOcean Droplet?
Point an A record straight at your Droplet’s public IPv4 and let Caddy or Nginx + Certbot issue a Let’s Encrypt cert via HTTP-01 or AgentDomains DNS-01.

    
How do I verify DNS propagation for DigitalOcean Droplet?
After running the CLI commands above, open our free /tools/dns-ssl-checker or run dig @1.1.1.1 do-app.makes.fyi to confirm Cloudflare and Google resolvers return your new record.

    
Can an AI agent set up DigitalOcean Droplet routing automatically via MCP?
Yes. Connect Claude Code, Cursor, or any MCP client to https://mcp.agentdomains.co and ask it to run claim_domain followed by add_dns_record.

Hetzner Cloud VPS

          
Use an A record (plus optional AAAA for Hetzner’s free /64 IPv6) and terminate TLS on your VPS with Caddy or Certbot DNS-01. Remember: AgentDomains edge proxy requires an upstream hostname, not a bare IP.

Linode (Akamai Cloud)

Fly.io
