Cloud VPS · A Record + TLS

Hetzner Cloud VPS

Use an A record (plus optional AAAA for Hetzner’s free /64 IPv6) and terminate TLS on your VPS with Caddy or Certbot DNS-01. Remember: AgentDomains edge proxy requires an upstream hostname, not a bare IP.

 Cloud VPS · A Record + TLS

DigitalOcean Droplet

Point an A record straight at your Droplet’s public IPv4 and let Caddy or Nginx + Certbot issue a Let’s Encrypt cert via HTTP-01 or AgentDomains DNS-01.

Fly.io

Use `agentdomains proxy` directly against `<app>.fly.dev`. You get instant edge HTTPS without running `fly certs add` or paying for a dedicated IPv4.

 PaaS & Containers · Edge HTTPS Proxy

Railway

Use `agentdomains proxy` pointing at your `*.up.railway.app` hostname. Zero custom-domain verification wait and instant HTTPS at our edge.

Raspberry Pi

Frequently asked questions

Should I use agentdomains proxy or an A record?

Use agentdomains proxy whenever your host gives you a public hostname (Fly.io, Railway, Render, Cloud Run, Tailscale Funnel). Use an A record + Caddy/Certbot whenever you have a bare server IPv4 address (Hetzner VPS, DigitalOcean Droplet, EC2, Raspberry Pi).

Does AgentDomains host my application code or containers?

No. AgentDomains hosts nothing — it gives your agent a real hostname under agentdomains.co or makes.fyi with writable DNS, forwarding, and an edge HTTPS reverse proxy in front of whatever server or PaaS you already run.

Are there bandwidth or request caps on proxied origins?

No request quotas and no bandwidth bills on either the 30-day free trial or the $10/yr Pro plan.
