Frequently asked questions

Should I use edge proxy or an A record?

Use edge proxy when your host gives you a public hostname like Fly.io or Railway. Use an A record plus Caddy when you own a bare IPv4 VPS.

Does AgentDomains host my app code or containers?

No. AgentDomains hosts no app code. It gives your server a real hostname with writable DNS, forwards, and an HTTPS edge proxy.

Are there bandwidth or request caps on proxied origins?

No. Neither the 30-day free trial nor the $10/yr Pro plan has request quotas or bandwidth bills.
