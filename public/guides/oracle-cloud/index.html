3. Oracle Cloud (OCI Free Tier) Origin Configuration

      

  

    Oracle Cloud (OCI Free Tier) server / platform config
    
  

  
# OCI Ubuntu images ship with restrictive iptables rules — open 80 & 443:
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 80 -j ACCEPT
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 443 -j ACCEPT
sudo netfilter-persistent save

Frequently asked questions

  

    
Should I use edge proxy or an A record for Oracle Cloud (OCI Free Tier)?
Point an A record at your OCI Always Free ARM VM public IP. Remember OCI requires opening ports 80/443 in BOTH the VCN Security List AND the VM’s local `iptables`!

    
How do I verify DNS propagation for Oracle Cloud (OCI Free Tier)?
After running the CLI commands above, open our free /tools/dns-ssl-checker or run dig @1.1.1.1 oci-arm.makes.fyi to confirm Cloudflare and Google resolvers return your new record.

    
Can an AI agent set up Oracle Cloud (OCI Free Tier) routing automatically via MCP?
Yes. Connect Claude Code, Cursor, or any MCP client to https://mcp.agentdomains.co and ask it to run claim_domain followed by add_dns_record.

  




      
Related Host Playbooks

      

        
          Major Clouds
          
AWS EC2

          
Attach an Elastic IP to your EC2 instance and point an A record at it (with Caddy/Nginx TLS), OR if you sit behind an AWS Application Load Balancer (`*.elb.amazonaws.com`), use `agentdomains proxy` for zero ACM cert paperwork.

        
        
          Major Clouds
          
AWS Lightsail

          
Attach a free Lightsail Static IP, create an A record with `agentdomains record`, and terminate HTTPS via Caddy or Bitnami’s `bncert-tool`.

        
        
          Major Clouds
          
Google Cloud Run

          
Use `agentdomains proxy` directly against your `*.a.run.app` hostname! Cloud Run custom domain mappings only work in select regions and take 15+ minutes — our edge proxy works globally in seconds.

        
        
          Webhooks & SaaS
          
Supabase Webhooks & Edge Functions

          
Use `agentdomains proxy` to give your webhook handler a clean, stable HTTPS URL (`https://supa-hooks.makes.fyi/db-events`) that survives backend host swaps without editing Supabase Database Webhooks.
