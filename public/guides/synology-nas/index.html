3. Synology NAS (DSM) Origin Configuration

      

  

    Synology NAS (DSM) server / platform config
    
  

  
# Synology Task Scheduler DDNS script (runs every 15 minutes):
IP=$(curl -s https://api.ipify.org)
curl -s -X POST "https://api.agentdomains.co/v1/subdomains/nas-box/records" \
  -H "Authorization: Bearer $AGENTDOMAINS_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{\"type\":\"A\",\"content\":\"$IP\"}"

Frequently asked questions

  

    
Should I use edge proxy or an A record for Synology NAS (DSM)?
Create an A record pointing to your home IP, add a Synology Task Scheduler curl/CLI job for dynamic IP updates, and configure DSM’s built-in Reverse Proxy (Control Panel → Login Portal → Advanced).

    
How do I verify DNS propagation for Synology NAS (DSM)?
After running the CLI commands above, open our free /tools/dns-ssl-checker or run dig @1.1.1.1 nas-box.makes.fyi to confirm Cloudflare and Google resolvers return your new record.

    
Can an AI agent set up Synology NAS (DSM) routing automatically via MCP?
Yes. Connect Claude Code, Cursor, or any MCP client to https://mcp.agentdomains.co and ask it to run claim_domain followed by add_dns_record.
