Origin-to-edge flow for Ruby on Rails: connect rails-demo.fly.dev to rails-demo.makes.fyi with automatic HTTPS.

1. Choose Mode: Edge Proxy vs DNS-01

Edge HTTPS Reverse Proxy

RECOMMENDED
  • Point at any public hostname without https://.
  • Cloudflare edge handles TLS 1.3 automatically.
  • Zero Certbot config and zero IP exposure.

A Record + ACME DNS-01

FOR BARE VPS
  • Point directly at your server IPv4 or IPv6 address.
  • Issue certs via Caddy or agentdomains txt DNS-01.
  • Works even when your firewall blocks port 80.
Ruby on Rails — 3-command AgentDomains setup 
agentdomains signup
agentdomains claim rails-demo --email you@example.com
agentdomains proxy rails-demo rails-demo.fly.dev

3. Ruby on Rails Origin Configuration

      
Apply this config on Ruby on Rails so headers, TLS, and routing match your new hostname.

      

  

    Ruby on Rails server / platform config
    
  

  
# config/environments/production.rb
config.hosts << "rails-demo.makes.fyi"
config.assume_ssl = true

Frequently asked questions

  

    
Should I use edge proxy or an A record for Ruby on Rails?
Use agentdomains proxy for Fly.io/Render/Railway Rails apps, or an A record when deploying via Kamal to a VPS. Whitelist the hostname in config.hosts.

    
How do I check DNS propagation for Ruby on Rails?
Open /tools/dns-ssl-checker or run dig @1.1.1.1 rails-demo.makes.fyi. Confirm both Cloudflare and Google return your record.

    
Can an AI agent configure Ruby on Rails routing via MCP?
Yes. Connect your client to https://mcp.agentdomains.co. Ask it to call claim_domain and set_proxy.
