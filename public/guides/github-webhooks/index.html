Frequently asked questions

  

    
Should I use edge proxy or an A record for GitHub Webhooks?
Use `agentdomains proxy` so GitHub delivers `push`, `pull_request`, and `check_run` events over verified HTTPS to `https://gh-hooks.makes.fyi/webhook`.

    
How do I verify DNS propagation for GitHub Webhooks?
After running the CLI commands above, open our free /tools/dns-ssl-checker or run dig @1.1.1.1 gh-hooks.makes.fyi to confirm Cloudflare and Google resolvers return your new record.

    
Can an AI agent set up GitHub Webhooks routing automatically via MCP?
Yes. Connect Claude Code, Cursor, or any MCP client to https://mcp.agentdomains.co and ask it to run claim_domain followed by set_proxy.
