Frequently asked questions

Does AgentDomains replace Instant Domain Search MCP for buying a .com domain?

No. AgentDomains provides managed subdomains under agentdomains.co and makes.fyi — not transferable ICANN second-level domains. If you must legally own and transfer a .com brand name, use a registrar like Cloudflare Registrar or Porkbun.

How does pricing compare between AgentDomains and Instant Domain Search MCP?

AgentDomains starts with a 30-day free trial (10 names, no card) and Pro is $10/yr ($1/mo) for up to 100 names with zero bandwidth bills. Instant Domain Search MCP: Search tool is free; actual registration redirects to partner registrars (~$12+/yr per domain).

Can an AI agent switch from Instant Domain Search MCP to AgentDomains via MCP?

Yes. Connect your agent to https://mcp.agentdomains.co (or npx -y agentdomains-mcp) and use signup, claim_domain, and set_proxy or add_dns_record.
