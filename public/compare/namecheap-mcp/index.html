Frequently asked questions

Does AgentDomains replace Namecheap + MCP for buying a .com domain?

No. AgentDomains provides managed subdomains under agentdomains.co and makes.fyi — not transferable ICANN second-level domains. If you must legally own and transfer a .com brand name, use a registrar like Cloudflare Registrar or Porkbun.

How does pricing compare between AgentDomains and Namecheap + MCP?

AgentDomains starts with a 30-day free trial (10 names, no card) and Pro is $10/yr ($1/mo) for up to 100 names with zero bandwidth bills. Namecheap + MCP: Real TLD registrations (~$11.28 yr 1, ~$15.88/yr renewal per .com); API access requires account spend/domain minimum.

Can an AI agent switch from Namecheap + MCP to AgentDomains via MCP?

Yes. Connect your agent to https://mcp.agentdomains.co (or npx -y agentdomains-mcp) and use signup, claim_domain, and set_proxy or add_dns_record.
