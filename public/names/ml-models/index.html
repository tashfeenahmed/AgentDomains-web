How to name & route ML Model Endpoints

Recommended Pattern

AI & AGENTS
  • Keep ML Model Endpoints hostnames short and clear so MCP clients, webhook senders, and humans read them fast.
  • Use agentdomains proxy for PaaS origins like ml-serve.fly.dev. Edge TLS terminates on port 443 with no certificate setup.
  • Pair infer-io.agentdomains.co for production traffic with embed-api.agentdomains.co for isolated prompt or tool tests.

Quick Launch Command

CLI / MCP

Claim ml-serve.agentdomains.co and attach your origin in one line:

ML Model Endpoints launch 
agentdomains claim ml-serve --email you@example.com --domain agentdomains.co && agentdomains proxy ml-serve ml-serve.fly.dev --domain agentdomains.co
