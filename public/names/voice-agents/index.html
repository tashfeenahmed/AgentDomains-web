How to name & route Voice Agents

Recommended Pattern

AI & AGENTS
  • Keep Voice Agents hostnames short and clear so MCP clients, webhook senders, and humans read them fast.
  • Use agentdomains proxy for PaaS origins like voice-ai.fly.dev. Edge TLS terminates on port 443 with no certificate setup.
  • Pair call-bot.agentdomains.co for production traffic with talk-ops.agentdomains.co for isolated prompt or tool tests.

Quick Launch Command

CLI / MCP

Claim voice-ai.agentdomains.co and attach your origin in one line:

Voice Agents launch 
agentdomains claim voice-ai --email you@example.com --domain agentdomains.co && agentdomains proxy voice-ai voice-ai.fly.dev --domain agentdomains.co
