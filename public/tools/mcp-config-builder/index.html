Frequently asked questions

  

    
Does the live Streamable HTTP handshake tester send my API key anywhere else?
No. The browser sends the JSON-RPC POST directly to the MCP URL you enter (default https://mcp.agentdomains.co). Nothing is logged or sent to any third-party backend.

    
Why does the handshake tester work without an API key on mcp.agentdomains.co?
MCP initialize and tools/list are public protocol discovery calls on mcp.agentdomains.co (along with check_availability and signup), so you can verify connectivity and inspect all 20 tools before entering a key.
