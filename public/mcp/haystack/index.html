1. Install & Configure Haystack (deepset)

Haystack (deepset) — Streamable HTTP config 
from haystack_integrations.tools.mcp import MCPToolset, StreamableHttpServerInfo
from haystack.utils import Secret

server_info = StreamableHttpServerInfo(
    url="https://mcp.agentdomains.co",
    token=Secret.from_env_var("AGENTDOMAINS_API_KEY"),
)
toolset = MCPToolset(server_info=server_info)
Haystack (deepset) — Local stdio config 
from haystack_integrations.tools.mcp import MCPToolset, StdioServerInfo

server_info = StdioServerInfo(
    command="npx",
    args=["-y", "agentdomains-mcp"],
    env={"AGENTDOMAINS_API_KEY": "adom_YOUR_KEY"},
)
toolset = MCPToolset(server_info=server_info)

3. Haystack (deepset)-Specific Gotchas

  • Install mcp-haystack (`pip install mcp-haystack`) for StreamableHttpServerInfo and MCPToolset.
  • Use Secret.from_env_var("AGENTDOMAINS_API_KEY") so Haystack serializes pipeline YAML safely without leaking tokens.
  • Pass tool_names=["check_availability","claim_domain","set_proxy"] to MCPToolset when you only want a subset of tools.

Frequently asked questions

Does Haystack (deepset) work with hosted https://mcp.agentdomains.co or stdio?

Haystack (deepset) supports Streamable HTTP & stdio. We recommend hosted Streamable HTTP (https://mcp.agentdomains.co) whenever supported because it requires zero local Node.js runtime, or npx -y agentdomains-mcp for local stdio setups.

Where does Haystack (deepset) store its MCP configuration?

Python: haystack_integrations.tools.mcp (MCPToolset). Keep your adom_ API key in an environment variable or user-scoped config rather than committing it to Git.

How much does it cost to claim domains from Haystack (deepset)?

Every new account includes a 30-day free trial with up to 10 names (no credit card required). Pro is $10/year or $1/month for up to 100 names with visitor stats and priority support.
