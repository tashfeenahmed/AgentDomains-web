AgentDomains MCP for Microsoft AutoGen

Load AgentDomains into Microsoft AutoGen 0.4+ via autogen_ext.tools.mcp StreamableHttpServerParams or StdioServerParams.

1. Install & Configure Microsoft AutoGen

Microsoft AutoGen — Streamable HTTP config 
from autogen_ext.tools.mcp import StreamableHttpServerParams, mcp_server_tools

params = StreamableHttpServerParams(
    url="https://mcp.agentdomains.co",
    headers={"Authorization": "Bearer adom_YOUR_KEY"},
)
tools = await mcp_server_tools(params)
Microsoft AutoGen — Local stdio config 
from autogen_ext.tools.mcp import StdioServerParams, mcp_server_tools

params = StdioServerParams(
    command="npx",
    args=["-y", "agentdomains-mcp"],
    env={"AGENTDOMAINS_API_KEY": "adom_YOUR_KEY"},
)
tools = await mcp_server_tools(params)

3. Microsoft AutoGen-Specific Gotchas

  • Install autogen-ext[mcp] alongside autogen-agentchat >= 0.4 for StreamableHttpServerParams.
  • Pass tools into AssistantAgent(..., tools=tools, reflect_on_tool_use=True) so the agent explains the live FQDN returned by claim_domain.
  • Use a UserProxyAgent approval gate before letting autonomous teams call delete_domain.

Frequently asked questions

Does Microsoft AutoGen work with hosted https://mcp.agentdomains.co or stdio?

Microsoft AutoGen supports Streamable HTTP & stdio. We recommend hosted Streamable HTTP (https://mcp.agentdomains.co) whenever supported because it requires zero local Node.js runtime, or npx -y agentdomains-mcp for local stdio setups.

Where does Microsoft AutoGen store its MCP configuration?

Python: autogen_ext.tools.mcp (StreamableHttpServerParams / StdioServerParams). Keep your adom_ API key in an environment variable or user-scoped config rather than committing it to Git.

How much does it cost to claim domains from Microsoft AutoGen?

Every new account includes a 30-day free trial with up to 10 names (no credit card required). Pro is $10/year or $1/month for up to 100 names with visitor stats and priority support.
