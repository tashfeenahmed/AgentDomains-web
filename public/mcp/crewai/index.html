1. Install & Configure CrewAI

CrewAI — Streamable HTTP config 
from crewai import Agent
from crewai_tools import MCPServerAdapter

server_params = {
    "url": "https://mcp.agentdomains.co",
    "transport": "streamable-http",
    "headers": {"Authorization": "Bearer adom_YOUR_KEY"},
}

with MCPServerAdapter(server_params) as tools:
    devops_agent = Agent(
        role="Release Engineer",
        goal="Publish every build on a live HTTPS hostname",
        backstory="Automates DNS and edge TLS for agent deployments.",
        tools=tools,
    )
CrewAI — Local stdio config 
from mcp import StdioServerParameters
from crewai_tools import MCPServerAdapter

params = StdioServerParameters(
    command="npx",
    args=["-y", "agentdomains-mcp"],
    env={"AGENTDOMAINS_API_KEY": "adom_YOUR_KEY"},
)
with MCPServerAdapter(params) as tools:
    ...

3. CrewAI-Specific Gotchas

  • Use "streamable-http" (hyphenated) in CrewAI MCPServerAdapter server_params.
  • Keep the MCPServerAdapter context manager open for the entire crew.kickoff() call so tool connections stay alive.
  • Give only the deployment agent write tools; read-only agents only need check_availability and get_domain.

Frequently asked questions

Does CrewAI work with hosted https://mcp.agentdomains.co or stdio?

CrewAI supports Streamable HTTP & stdio. We recommend hosted Streamable HTTP (https://mcp.agentdomains.co) whenever supported because it requires zero local Node.js runtime, or npx -y agentdomains-mcp for local stdio setups.

Where does CrewAI store its MCP configuration?

Python: crewai_tools.MCPServerAdapter. Keep your adom_ API key in an environment variable or user-scoped config rather than committing it to Git.

How much does it cost to claim domains from CrewAI?

Every new account includes a 30-day free trial with up to 10 names (no credit card required). Pro is $10/year or $1/month for up to 100 names with visitor stats and priority support.
