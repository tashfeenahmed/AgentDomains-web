1. Install & Configure Vercel AI SDK

Vercel AI SDK — Streamable HTTP config 
import { experimental_createMCPClient as createMCPClient, generateText } from "ai";
import { StreamableHTTPClientTransport } from "@modelcontextprotocol/sdk/client/streamableHttp.js";
import { openai } from "@ai-sdk/openai";

const mcpClient = await createMCPClient({
  transport: new StreamableHTTPClientTransport(
    new URL("https://mcp.agentdomains.co"),
    { requestInit: { headers: { Authorization: `Bearer ${process.env.AGENTDOMAINS_API_KEY}` } } }
  ),
});
const tools = await mcpClient.tools();
const result = await generateText({ model: openai("gpt-4.1"), tools, prompt: "Check if edge-demo is free on makes.fyi" });
await mcpClient.close();
Vercel AI SDK — Local stdio config 
import { experimental_createMCPClient as createMCPClient } from "ai";
import { Experimental_StdioMCPTransport } from "ai/mcp-stdio";

const mcpClient = await createMCPClient({
  transport: new Experimental_StdioMCPTransport({
    command: "npx",
    args: ["-y", "agentdomains-mcp"],
    env: { AGENTDOMAINS_API_KEY: process.env.AGENTDOMAINS_API_KEY ?? "" },
  }),
});

3. Vercel AI SDK-Specific Gotchas

  • On Vercel Serverless / Edge Functions, always use StreamableHTTPClientTransport — stdio subprocesses cannot spawn in edge runtimes.
  • Call await mcpClient.close() inside a try/finally block or onFinish callback when streaming responses.
  • Enable maxSteps >= 4 in streamText/generateText so the model can chain check_availability → claim_domain → set_proxy.

Frequently asked questions

Does Vercel AI SDK work with hosted https://mcp.agentdomains.co or stdio?

Vercel AI SDK supports Streamable HTTP & stdio. We recommend hosted Streamable HTTP (https://mcp.agentdomains.co) whenever supported because it requires zero local Node.js runtime, or npx -y agentdomains-mcp for local stdio setups.

Where does Vercel AI SDK store its MCP configuration?

TypeScript: ai (experimental_createMCPClient) + @modelcontextprotocol/sdk. Keep your adom_ API key in an environment variable or user-scoped config rather than committing it to Git.

How much does it cost to claim domains from Vercel AI SDK?

Every new account includes a 30-day free trial with up to 10 names (no credit card required). Pro is $10/year or $1/month for up to 100 names with visitor stats and priority support.
