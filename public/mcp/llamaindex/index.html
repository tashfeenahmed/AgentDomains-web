1. Install & Configure LlamaIndex

Choose hosted Streamable HTTP for zero local setup, or pick local stdio to reuse your Go CLI config.

LlamaIndex — Streamable HTTP config 
from llama_index.tools.mcp import BasicMCPClient, McpToolSpec

client = BasicMCPClient(
    "https://mcp.agentdomains.co",
    headers={"Authorization": "Bearer adom_YOUR_KEY"},
)
tool_spec = McpToolSpec(client=client)
tools = await tool_spec.to_tool_list_async()
LlamaIndex — Local stdio config 
from llama_index.tools.mcp import BasicMCPClient, McpToolSpec

client = BasicMCPClient("npx", args=["-y", "agentdomains-mcp"])
tool_spec = McpToolSpec(client=client)
tools = await tool_spec.to_tool_list_async()

3. LlamaIndex Setup Notes

  • Install llama-index-tools-mcp >= 0.2 to ensure Streamable HTTP URL auto-detection works without SSE fallback errors.
  • Pass allowed_tools=["check_availability","claim_domain","set_proxy"] into McpToolSpec to restrict write scope.
  • Use to_tool_list_async() inside async FastAPI or workflow loops rather than the blocking sync helper.

Frequently asked questions

Does LlamaIndex work with Streamable HTTP or stdio?

LlamaIndex supports Streamable HTTP & stdio. Pick hosted Streamable HTTP when available for zero local Node setup, or run npx -y agentdomains-mcp for stdio.

Where does LlamaIndex store its MCP config?

Store it in Python: llama_index.tools.mcp (BasicMCPClient + McpToolSpec). Keep your adom_ API key in an env var and never commit it to Git.

How much does it cost to claim domains from LlamaIndex?

Start with a 30-day free trial for 10 names with no card. Pro costs $10/yr or $1/mo for up to 100 names.
