Frequently asked questions

What is the difference between Streamable HTTP and stdio MCP?

Streamable HTTP runs at https://mcp.agentdomains.co with no local Node install. Local stdio runs via npx and reads your Go CLI config file.

Can my AI agent connect before I have an API key?

Yes. Connect without an Authorization header and call the signup tool first. Pass the returned adom_ key on your next tool calls.

How many MCP tools does AgentDomains expose?

Both transports expose the same 20 tools. They cover signup, domain claims, DNS records, ACME tokens, forwards, edge proxies, and stats.
