Frequently asked questions

What is the difference between hosted Streamable HTTP and local stdio MCP?

Hosted Streamable HTTP (https://mcp.agentdomains.co) requires zero Node.js install and works from cloud agents, editors, and serverless runtimes. Local stdio (npx -y agentdomains-mcp) runs on your machine and can automatically reuse ~/.agentdomains/config.json from the Go CLI.

Can my AI agent connect before I have an API key?

Yes. Connect to https://mcp.agentdomains.co without an Authorization header, call the signup tool to receive an adom_ key immediately, and pass that key as api_key on subsequent calls.

How many MCP tools does AgentDomains expose?

Both transports expose the exact same 20 tools covering check_availability, signup, claim_domain, DNS records (A, AAAA, CNAME, TXT), add_acme_challenge, set_forward, set_proxy, delegate_nameservers, get_visits, and billing.
