1. Install & Configure Zed Editor

Choose hosted Streamable HTTP for zero local setup, or pick local stdio to reuse your Go CLI config.

Zed Editor — Streamable HTTP config 
{
  "context_servers": {
    "agentdomains": {
      "command": {
        "path": "npx",
        "args": [
          "-y",
          "mcp-remote",
          "https://mcp.agentdomains.co",
          "--header",
          "Authorization: Bearer adom_YOUR_KEY"
        ],
        "env": {}
      }
    }
  }
}
Zed Editor — Local stdio config 
{
  "context_servers": {
    "agentdomains": {
      "command": {
        "path": "npx",
        "args": [
          "-y",
          "agentdomains-mcp"
        ],
        "env": {
          "AGENTDOMAINS_API_KEY": "adom_YOUR_KEY"
        }
      }
    }
  }
}

3. Zed Editor Setup Notes

  • Zed calls MCP servers "context_servers" inside ~/.config/zed/settings.json.
  • In Zed Agent Panel, make sure the active profile (e.g. Write) has the agentdomains context server enabled.
  • If Zed cannot find npx on macOS, supply the full binary path under command.path.

Frequently asked questions

Does Zed Editor work with Streamable HTTP or stdio?

Zed Editor supports stdio (native) & HTTP bridge. Pick hosted Streamable HTTP when available for zero local Node setup, or run npx -y agentdomains-mcp for stdio.

Where does Zed Editor store its MCP config?

Store it in ~/.config/zed/settings.json (context_servers). Keep your adom_ API key in an env var and never commit it to Git.

How much does it cost to claim domains from Zed Editor?

Start with a 30-day free trial for 10 names with no card. Pro costs $10/yr or $1/mo for up to 100 names.
