1. Install & Configure Windsurf (Cascade)

Windsurf (Cascade) — Streamable HTTP config 
{
  "mcpServers": {
    "agentdomains": {
      "serverUrl": "https://mcp.agentdomains.co",
      "headers": {
        "Authorization": "Bearer adom_YOUR_KEY"
      }
    }
  }
}
Windsurf (Cascade) — Local stdio config 
{
  "mcpServers": {
    "agentdomains": {
      "command": "npx",
      "args": [
        "-y",
        "agentdomains-mcp"
      ],
      "env": {
        "AGENTDOMAINS_API_KEY": "adom_YOUR_KEY"
      }
    }
  }
}

3. Windsurf (Cascade)-Specific Gotchas

  • Windsurf remote HTTP entries use "serverUrl" rather than "url" in ~/.codeium/windsurf/mcp_config.json.
  • Open the Cascade MCP toolbar and click Refresh after editing mcp_config.json; Windsurf caches the tool catalog per window.
  • Keep total enabled MCP tools across all servers under Windsurf’s active tool cap by disabling unused servers.

Frequently asked questions

Does Windsurf (Cascade) work with hosted https://mcp.agentdomains.co or stdio?

Windsurf (Cascade) supports Streamable HTTP & stdio. We recommend hosted Streamable HTTP (https://mcp.agentdomains.co) whenever supported because it requires zero local Node.js runtime, or npx -y agentdomains-mcp for local stdio setups.

Where does Windsurf (Cascade) store its MCP configuration?

~/.codeium/windsurf/mcp_config.json. Keep your adom_ API key in an environment variable or user-scoped config rather than committing it to Git.

How much does it cost to claim domains from Windsurf (Cascade)?

Every new account includes a 30-day free trial with up to 10 names (no credit card required). Pro is $10/year or $1/month for up to 100 names with visitor stats and priority support.
