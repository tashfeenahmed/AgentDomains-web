Webhook HTTPS & TLS Requirements Explained

Why Stripe, GitHub, Slack, Meta, and Twilio reject raw IPs, self-signed certs, and 302 redirects — and how edge proxying satisfies all of them.

1. Engineering Breakdown

Production webhook senders validate three things before delivering events: a valid CA-signed certificate matching the URL hostname (SNI), port 443 HTTPS, and a direct 2xx response without following POST redirects. `agentdomains proxy` satisfies all three instantly.

Common Pitfalls

  • Always verify HMAC signatures (`Stripe-Signature`, `X-Hub-Signature-256`) using the raw unparsed request body.
