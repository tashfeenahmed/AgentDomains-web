DNS over HTTPS (DoH) Explained

Query live DNS records from browsers, CI jobs, or sandboxes using Cloudflare and Google JSON DoH APIs.

Record Type A
Sub-Label @
Default TTL 300s Auto
MCP Tool get_domain

Exact DNS wire fields: HOST identifies the label, TYPE picks the record format, TTL sets cache duration, TARGET holds the answer.

1. Engineering Breakdown

DNS over HTTPS (RFC 8484) sends DNS queries inside standard port 443 HTTPS requests. It bypasses ISP DNS blocks and lets browser tools like /tools/dns-ssl-checker inspect live records directly.

Common Pitfalls

  • Always set Accept: application/dns-json when calling Cloudflare’s /dns-query endpoint, otherwise it expects binary wire-format DNS.

3. Exact CLI, curl & MCP JSON-RPC Payloads

      
Pick your preferred interface below and copy the working payload.

      

        

          
          
          
        

        

          

  

    CLI command
    
  

  
curl -H "accept: application/dns-json" "https://cloudflare-dns.com/dns-query?name=myapp.makes.fyi&type=A"



        

        

          

  

    REST API via curl
    
  

  
curl -s "https://dns.google/resolve?name=myapp.makes.fyi&type=TXT"



        

        

          

  

    POST https://mcp.agentdomains.co (get_domain)
    
  

  
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "get_domain",
    "arguments": {
      "label": "myapp"
    }
  }
}
