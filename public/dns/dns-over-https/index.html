DNS over HTTPS (DoH) Explained

Query live authoritative DNS records straight from browsers, CI scripts, or locked-down sandboxes using Cloudflare and Google JSON DoH APIs.

1. Engineering Breakdown

DNS over HTTPS (RFC 8484) encapsulates DNS queries inside standard HTTPS requests on port 443, bypassing ISP DNS hijacking and allowing browser-based diagnostic tools (like our `/tools/dns-ssl-checker`) to verify live DNS propagation over CORS.

Common Pitfalls

  • Always set `Accept: application/dns-json` when calling Cloudflare’s `/dns-query` endpoint, otherwise it expects binary wire-format DNS.

Frequently asked questions

  

    
What is DNS over HTTPS (DoH)?
Query live authoritative DNS records straight from browsers, CI scripts, or locked-down sandboxes using Cloudflare and Google JSON DoH APIs.

    
How do I automate DNS over HTTPS (DoH) with AgentDomains?
Run `curl -H "accept: application/dns-json" "https://cloudflare-dns.com/dns-query?name=myapp.makes.fyi&type=A"` from the Go CLI, call the REST API over curl, or invoke the `get_domain` tool on https://mcp.agentdomains.co.
