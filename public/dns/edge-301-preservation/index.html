Path & Query Preservation on Edge Redirects Explained

Control whether `myapp.makes.fyi/pricing?ref=gh` redirects to `https://target.com/pricing?ref=gh` or collapses to the target root.

1. Engineering Breakdown

By default, AgentDomains `set_forward` sets `preserve_path: true`, appending the incoming path and query string onto your target URL so deep links stay intact. Set `preserve_path: false` when you want every path on an old promo domain to land cleanly on a single landing page.

Common Pitfalls

  • Avoid `cloak: true` (iframe cloaking) for modern web apps — most sites send `X-Frame-Options: DENY` or `frame-ancestors` CSP headers that block iframes.
